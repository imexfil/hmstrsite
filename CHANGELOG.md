# История изменений - Hamster CRMP Cabinet

## [2.0.0] - PHP Migration

### 🔄 Миграция на PHP
- **BREAKING:** Заменен Node.js backend на PHP API
- Теперь работает на обычном PHP хостинге (MyArena compatible)
- Не требуется запуск Node.js сервера
- Полная совместимость с функционалом

### ✨ Новая статистика игрока

#### Добавлено в профиль:
- **Опыт (exp)** - отображается в шапке профиля и рядом с уровнем
- **Уровень боевого пропуска (bp_level)** - в статбаре и карточке персонажа
- **Последний вход (last_login)** - исправлено форматирование даты
- **Отыграно за час (game_for_hour)** - время в формате "X ч Y мин"
- **За день (game_for_day)** - время игры за сегодня
- **Отыграно вчера (game_for_day_prev)** - статистика за предыдущий день

#### Слоты:
- Доступные слоты на авто (car_slots)
- На бизнес (biz_slot)
- На дом (home_slot)
- На гараж (garage_slot)

#### Имущество (новые секции):

**Бизнесы:**
- Список всех бизнесов игрока из таблицы `business` (по owner_id)
- Информация: название, тип (24/7, заправка, и т.д.), город
- Касса, количество товара, цена покупки, аренда
- Отображается как "Бизнеса нет" если нет владений

**Дома:**
- Список всех домов игрока из таблицы `houses` (по owner_id)
- Информация: название, тип (эконом, премиум, и т.д.), город
- Цена, аренда, улучшения
- Отображается как "Дома нет" если нет владений

### 🔐 Безопасность

**Новые файлы:**
- `api/.htaccess` - защита config.php от прямого доступа
- `api/config.php` - централизованные настройки БД
- Использование PDO с prepared statements (защита от SQL injection)
- Проверка паролей через MD5/SHA1/SHA256 хэши

**Защита данных:**
- Данные БД не доступны через браузер
- .htaccess блокирует прямой доступ к config.php
- CORS настроен для API endpoints

### 🗑️ Устаревшие файлы

После миграции можно удалить:
- `server.js` - больше не используется
- `package.json` - Node.js зависимости не нужны
- `package-lock.json`
- `.env` - данные перенесены в api/config.php
- `node_modules/` - папка зависимостей

### 🔄 API Endpoints

**Старые (Node.js):**
```
POST /api/account/login
GET  /api/account/:id/cars
GET  /api/account/:id/stats
GET  /api/account/:id/family
```

**Новые (PHP):**
```
POST api/login.php
GET  api/cars.php?id={id}
GET  api/stats.php?id={id}
GET  api/family.php?id={id}
```

### 📊 База данных

**Используемые таблицы:**
- `accounts` - основные данные игрока
- `ownable_cars` - транспорт (по owner_id)
- `business` - бизнесы игрока (по owner_id)
- `houses` - дома игрока (по owner_id)
- `family` - информация о семьях

**Новые используемые поля из accounts:**
- `exp` - опыт игрока
- `bp_level` - уровень боевого пропуска
- `game_for_hour` - отыграно за час
- `game_for_day` - отыграно за день
- `game_for_day_prev` - отыграно вчера
- `car_slots` - доступные слоты на машины
- `biz_slot` - слоты на бизнес
- `home_slot` - слоты на дома
- `garage_slot` - слоты на гаражи
