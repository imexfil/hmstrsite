# 🎮 Hamster CRMP - Личный кабинет

Веб-интерфейс для просмотра статистики игроков Hamster CRMP сервера.

## 🚀 Быстрый старт

### Для MyArena хостинга:

1. **Загрузите все файлы** из этой папки на хостинг через FTP
2. **Настройте БД** в файле `api/config.php`
3. **Проверьте безопасность** - файл `api/config.php` не должен открываться в браузере
4. **Войдите на сайт** и проверьте работу

Подробнее: [DEPLOY_INSTRUCTIONS.md](DEPLOY_INSTRUCTIONS.md)

## ✨ Возможности

### Статистика игрока:
- ✅ Основная информация (уровень, exp, деньги)
- ✅ Уровень боевого пропуска
- ✅ Время игры (за час, день, вчера)
- ✅ Доступные слоты (авто, бизнес, дом, гараж)
- ✅ Последний вход
- ✅ Навыки владения оружием

### Имущество:
- ✅ **Транспорт** - список всех машин игрока
- ✅ **Бизнесы** - владения с подробной информацией
- ✅ **Дома** - недвижимость игрока

### Безопасность:
- ✅ Защита данных БД через .htaccess
- ✅ Безопасная авторизация с проверкой хэшей
- ✅ SQL injection защита через PDO

## 📋 Требования

- PHP 7.4 или выше
- MySQL/MariaDB
- PDO extension (обычно включено)
- Apache с .htaccess (рекомендуется)

После загрузки на хостинг:

1. Откройте `test_connection.html` в браузере
2. Нажмите кнопки тестирования API
3. Проверьте, что все endpoints возвращают данные

## ⚠️ Решение проблем

### Не работает вход в кабинет
- Проверьте данные в `api/config.php`
- Откройте консоль браузера (F12) и посмотрите ошибки
- Проверьте `api/login.php` через `test_connection.html`

### Показываются прочерки вместо данных
- **Выйдите из кабинета и войдите заново**
- Или очистите localStorage в браузере (F12 → Application → Local Storage)
- Старая версия данных автоматически очистится

### config.php доступен в браузере
- Проверьте, что `.htaccess` загружен в папку `api/`
- Переместите `config.php` выше корня сайта
- Добавьте защиту через PHP (см. DEPLOY_INSTRUCTIONS.md)

### Не отображаются бизнесы/дома
- Проверьте, что в таблицах `business` и `houses` есть записи с `owner_id = id игрока`
- Поле `business` в таблице `accounts` НЕ используется для списка
- Список берется по `owner_id` из соответствующих таблиц

## 🔐 Безопасность

### Обязательно проверьте:

1. **config.php защищен** - https://ваш-сайт.ru/api/config.php должен давать 403 ошибку
2. **.htaccess загружен** в папку `api/`
3. **Пароли БД** не доступны через браузер

### Рекомендации:

- Используйте HTTPS для продакшена
- Регулярно обновляйте пароли БД
- Храните резервные копии БД
