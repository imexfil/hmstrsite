# 🚀 НАЧНИ ЗДЕСЬ!

## Что делать, чтобы всё заработало:

### 1️⃣ Загрузи файлы на хостинг

Загрузи ВСЮ папку `hmstr` на твой хостинг через FTP (FileZilla, Total Commander и т.д.)

### 2️⃣ Открой debug страницу

Открой в браузере: **`https://твой-сайт.ru/debug.html`**

Эта страница автоматически проверит:
- ✅ Работает ли PHP
- ✅ Подключается ли к базе данных
- ✅ Сколько аккаунтов в базе
- ✅ Какие PHP расширения установлены

### 3️⃣ Проверь результаты

**Если всё ОК - увидишь:**
```json
{
  "status": "ok",
  "php_version": "7.4.x",
  "database": "connected",
  "accounts_count": 123
}
```

**Если ошибка - увидишь:**
```json
{
  "database": "error",
  "db_error": "подробное описание ошибки"
}
```

### 4️⃣ Если есть ошибка БД

Открой файл `api/config.php` и проверь данные:
- DB_HOST
- DB_USER  
- DB_PASSWORD
- DB_NAME

### 5️⃣ Протестируй логин

На странице `debug.html`:
1. Введи игровой ник (например: Forza_Bedolaga)
2. Введи пароль от аккаунта
3. Нажми "Test Login"

**Если пароль правильный - увидишь все данные игрока!**

### 6️⃣ Очисти старый кеш

Если раньше входил в кабинет:
1. На странице `debug.html` нажми **"Clear Storage"**
2. Или выйди из кабинета через кнопку "Выйти"

### 7️⃣ Войди в кабинет

Теперь открой: **`https://твой-сайт.ru/account.html`**

Введи ник и пароль - должно работать!

## ❓ Частые проблемы

### "Unexpected token '<'" при входе
- API возвращает HTML вместо JSON
- Открой `api/test.php` в браузере напрямую
- Посмотри что он возвращает
- Скорее всего ошибка в подключении к БД

### Показывает прочерки вместо данных
- Выйди из кабинета и войди заново
- Или нажми "Clear Storage" на debug.html

### "Access denied" при входе
- Неправильный пароль
- Попробуй другой пароль
- Пароль может быть захеширован (MD5/SHA1/SHA256)

### config.php открывается в браузере
- Проверь что файл `api/.htaccess` загружен
- Переименуй `api/config.php` в `api/config.inc.php`
- Или перемести его выше корня сайта
